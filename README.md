## Tech Stack & Skills Demonstrated

Throughout these projects, you will see practical applications of:

- **Data Visualization:** Tableau, Power BI, Matplotlib, Seaborn
- **Data Wrangling:** Cleaning, transforming, and modeling messy datasets

- **Statistical Analysis:** A/B Testing, Regression, Exploratory Data Analysis (EDA)
- **Tools:** Jupyter Notebooks, Excel, Git/GitHub
